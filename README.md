## 🌍 ¿Qué es?

**Diario de un Explorador** es una aplicación móvil creada como proyecto de **Desarrollo de Aplicaciones Móviles**.

> Es un espacio pensado para convertir lugares, momentos y descubrimientos en recuerdos que formen parte de una aventura personal.

## ✨ La idea

```text
        Explorar  ─────▶  Vivir  ─────▶  Recordar
           🗺️              ✨              📖
```

Este proyecto busca reunir la emoción de descubrir nuevos lugares con la experiencia de llevar un diario digital.

## 🧭 Filosofía del proyecto

- **Curiosidad:** observar más allá de lo cotidiano.
- **Recuerdos:** guardar los momentos importantes.
- **Exploración:** dar valor a cada viaje y descubrimiento.
- **Diseño:** crear una experiencia clara, útil y agradable.
