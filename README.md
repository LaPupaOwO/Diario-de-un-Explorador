# Diario de un Explorador

**Diario de un Explorador** es un proyecto de aplicación móvil desarrollado como parte de la asignatura de Desarrollo de Aplicaciones Móviles. La propuesta gira en torno a la idea de un diario para acompañar las experiencias de exploración.

La aplicación está desarrollada con **Flutter** y **Dart**, con el objetivo de crear una experiencia móvil multiplataforma.
